Запусти **субагента** (Agent/Task tool) як незалежного ревьюера: він не бачив, як писали код.
Дай йому завдання дослівно:

> Прочитай CLAUDE.md, docs/SPEC.md §2, потім app/parsing.py, app/rules/, tests/.
> Нічого не виправляй. Знайди, де сервіс може сказати pass (або не показати технологу
> порушення), хоча порушення є. Для кожної підозри придумай конкретну екстракцію, на якій
> це станеться, і доведи запуском (docker compose run --rm test pytest -k … або python
> -c …). Неперевірене — «гіпотеза». Також: розбіжності з CLAUDE.md/SPEC.md, тести, що
> нічого не доводять, правила без legal_ref. Звіт: таблиця № | серйозність | файл:рядок
> | сценарій | доведено/гіпотеза | як виправити. Максимум 10 пунктів.

Далі сам: виправ усі доведені критичні й важливі (кожне — з регресійним тестом), гіпотези
перевір або запиши в NOTES.md. Ворота: `make test && make lint`.
Звіт ревьюера збережи в `docs/reviews/RR1.md`.
