# Кроки для автономного режиму

Людина після `/clear` пише одне: **«Виконай крок B2a»**. Claude Code читає CLAUDE.md
(розділ «Автономний режим») і `docs/steps/<крок>.md`, робить усе сам і звітує.
Чекліст рев'ю — `docs/steps/REVIEW.md`. Нотатки між кроками — `docs/NOTES.md`.

Порядок: B1b → B2a → B2b → B2c → RR1 → B3a → B3b → RR2 → B4a → B4b → B5a → B5b → B6 → B7.
⏸ — точки, де Claude Code зупиняється і чекає людину: кінець B1b (коротко), B4b, B6.
