# B4a — генератор синтетики (модель: Sonnet)

Прочитай `docs/SPEC.md` §4 і каталог порушень (`docs/OVERVIEW.md` §7, останній абзац).
`eval/generate.py` — синтетичні етикетки на Pillow (DejaVu Sans / Bold):
- 6–8 шаблонів (йогурт, печиво, батончик, сік, хліб, соус…), тверді й рідкі;
- зворот: склад з виділеними алергенами (жирний або ВЕЛИКІ), «може містити», таблиця з
  комою і інколи «<0,5»; фронт: назва + 0–2 твердження;
- формулювання з `eval/pools/dev.yaml` і `eval/pools/test.yaml` (різні!), з формами поза
  словником і пастками-виключеннями;
- каталог порушень + чисті (зокрема «без цукру» при «<0,5»);
- якість: чистий, розмиття, поворот ±7°, JPEG 40 %;
- кейс = `eval/cases/<split>/<id>/`: фото, spec.json (частина), truth.json
  {violations: [{rule_id, target}], extraction: <правильна LabelExtraction — та сама
  структура, з якої малювали>, meta: {synthetic: true, quality, template}};
- seed; ~60 кейсів; dev/test 50/50 зі стратифікацією; `make generate`.
- Тести: детермінованість за seed; кожен тип порушення є в dev і test; пули не
  перетинаються.

Ворота: `make generate && make test && make lint`; відкрий (Read) 3 картинки — чисту, з
порушенням, зіпсовану: чи схожі на етикетки, чи видно жирні алергени.
Коміт: `feat(b4a): synthetic label generator`.
