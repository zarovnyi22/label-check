# Label Check

> Заготовка (B1a). Розділи заповнюються по ходу кроків; фінальна звірка з кодом — у B7.

## Що це

Сервіс за фото упаковки (1–4 фото) перевіряє маркування харчового продукту за законодавством
України: алергени (Закон № 2639-VIII) і твердження про поживну цінність (Наказ МОЗ № 1145).
Замінює ручну звірку технолога перед запуском продукту.

## Архітектура

Модель читає, код вирішує: vision-LLM лише транскрибує етикетку в JSON, а розбір чисел,
правила, пороги й вердикт — у коді з посиланнями на закон. _TODO (B3–B7)._

## Запуск за 3 команди

```bash
cp .env.example .env      # вписати GEMINI_API_KEY
make up                   # db + api на 127.0.0.1:8010
make health               # {"status":"ok","db":"ok",...}
```

Тести (без мережі й живого LLM): `make test`. Swagger UI: http://localhost:8010/docs
